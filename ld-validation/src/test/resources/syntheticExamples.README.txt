syntheticExamples.txt
======================

40 synthetic GL-string samples, modeled on the shape of real-world NGS HLA typing output
(the kind of file this tool is meant to analyze) without representing any real individual's
genotype. Every allele combination is drawn directly from a public NMDP haplotype frequency
reference table (population-level statistics, not any person's typing result) and recombined;
nothing here is copied from, or traceable back to, any specific source row or individual.

Three scenarios are deliberately represented, each exercising a real code path this project
has real regression history with:
  - plain allele ambiguity ("/") -- the ordinary shape of shallow/low-resolution NGS output
  - one locus pushed over ALLELE_AMBIGUITY_THRESHOLD, so AmbiguousGenotypeException gets
    exercised by a real batch run (samples synthetic-010, synthetic-038 as generated)
  - a "|" genotype-ambiguity G-group tie -- the exact mechanism behind the non-determinism
    investigated and fixed in PRs #122/#125

Generated by SyntheticGLStringGenerator (ld-tools), which needs a fuller NMDP five-locus
haplotype frequency reference file than the small ones bundled in this repo's own
src/main/resources/frequencies/std -- like the "2011 NMDP frequency files" noted elsewhere
in this project, that fuller reference data is not freely redistributable, so it's supplied
as a local file path rather than shipped here. The generator's own javadoc has the full
design rationale.

To regenerate (adjust the frequency file path to wherever your own copy lives):

    mvn -pl ld-tools -am package -DskipTests
    JAVA_OPTS="-Dorg.dash.hladb=3.65.0" \
      ld-tools/target/appassembler/bin/synthetic-gl-string-generator \
      -f /path/to/NMDP_FiveLocus_Freqs.csv \
      -o ld-validation/src/test/resources/syntheticExamples.txt

Pinning -Dorg.dash.hladb explicitly matters: the default HLADB resolution falls back to a
much smaller/older snapshot (confirmed 97 vs 684 G-groups loaded), which starves the
ambiguity/tie injection of real data to draw from. 3.65.0 is the version already validated
in this project's Phase 4a StAX work.

Default generation parameters (sample count, ambiguity rate, threshold-exceeding rate,
genotype-tie rate, random seed) are documented on SyntheticGLStringGenerator's CLI --help.
