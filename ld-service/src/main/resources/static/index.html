HLAHapV

HLA linkage disequilibrium detection — a browser front end for analyze-gl-strings. Same detection engine, same reports; results below include anomalies/warnings, not just clean matches.

Reference data

Terms for the 2026 NMDP frequencies. These are NMDP’s “Classical HLA Allele and Haplotype Frequency Estimates in US Populations” (doi:10.5281/zenodo.17966993), owned by NMDP and licensed CC BY-NC-ND 4.0: non-commercial use only, no derivatives, attribution required. They are not part of this software. The unmodified files are downloaded from Zenodo on first use and kept in this service’s cache; the nine-locus file alone is about 181 MB and needs roughly 6 GB of memory once loaded.

Cite as: NMDP, Classical HLA Allele and Haplotype Frequency Estimates in US Populations, Zenodo, doi:10.5281/zenodo.17966993.
